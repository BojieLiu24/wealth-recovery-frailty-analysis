# Manuscript-to-code coverage

See `coverage_matrix.csv` for the compact per-item map, operating mode, validation status and limitations. Main text: author-supplied final manuscript. Supplement: author-confirmed final PDF and S1–S12 source tables. Code and aggregate references are selected by scientific release identity rather than timestamp.

The main-model population targets are HRS 5,114, ELSA 699 and KLoSA 2,502. The landmark FI enters the primary outcome. Recovery is measured against the amount lost in the index shock. Neither a population target nor an aggregate reference authorizes hardcoding fitted results or selecting a later event to recover missing observations.

DATA_FREE_REPRODUCIBLE means aggregate verification or explicitly synthetic execution. It never means independent original-cohort re-estimation. RESTRICTED_DATA_REQUIRED indicates that numerical implementations exist but require authorized inputs and, for historical orchestration, locally rebuilt integrity assets. DOCUMENTED_ONLY indicates definitions or author reference text without an executable independently packaged generator. NOT_AVAILABLE identifies intentionally excluded/unreviewed assets.
